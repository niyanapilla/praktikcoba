HTML (HyperText Markup Language)

Bahasa markup yang digunakan untuk membuat struktur halaman web. HTML bukan bahasa pemrograman, melainkan bahasa yang memberi tahu browser isi sebuah halaman.

Fungsi HTML:

  • Membuat judul
  • Menampilkan paragraf
  • Menambahkan gambar

Contoh Dasar HTML

  • Deklarasi
  • Judul HTML
  • Paragraf HTML
  • Tautan HTML
  • Gambar HTML
